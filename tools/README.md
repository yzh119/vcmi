# Developer tools

The creature and town art pipeline has moved to
[yzh119/h3-art-pipeline](https://github.com/yzh119/h3-art-pipeline).

See its [reproduction guide](https://github.com/yzh119/h3-art-pipeline/blob/main/docs/REPRODUCING.md)
for setup, prompts, Blender workflows, resource export and mod validation.
The standalone repository contains tools and configuration; artwork and complete
mod packages remain outside the source repository. No engine changes are required
for these graphical replacements.

Historical work remains in this repository's Git history and
[PR #10](https://github.com/yzh119/vcmi/pull/10).
